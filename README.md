# Writer Studio

Writer Studio is a comprehensive, professional SaaS application built for writers to seamlessly craft, organize, and manage their stories, series, characters, and notes. Serving as a robust alternative to standard writing platforms like Wattpad, it offers an elegant, distraction-free environment packed with extensive features.

## Key Features

- **Extensive Organization:** Organize your work into Series, Stories, and Chapters with robust tagging, metadata, and custom sorting.
- **Professional Editor:** A fully-featured WYSIWYG editor akin to MS Word/LibreOffice, with support for LaTeX, inline comments, and chapter-wide notes.
- **Custom Export/Import:** Support for standard formats (PDF, EPUB) and proprietary encrypted formats (`.wstory`, `.wseries`, `.wset`) for secure sharing and backup.
- **Plugin System:** A highly extensible ecosystem supporting custom `.wext` plugins to modify UI/UX and add new features securely.
- **Responsive & Elegant Design:** A light, eye-friendly theme with a responsive layout adapted for desktop, tablet, and mobile viewing.

## Tech Stack
- **Backend:** Python FastAPI
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** SQLite
